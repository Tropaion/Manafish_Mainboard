# 12. Glossary

Terms and abbreviations used across these docs. Status labels are explained on
[Home](Home).

## 12.1 Terms

| Term | Meaning |
|---|---|
| `-mb.N` | Suffix of this repo's release tags. N counts mainboard releases of the same upstream version: `firmware-v1.0.4-mb.1`, `software-v1.2.0-rc.3-mb.1`. SemVer sorts `1.0.4-mb.1` before `1.0.4-rc.3` and `1.0.4`, so version-mismatch checks must compare for equality, not order (checked in **[planned: Phase 4]**). Never `-rc` in an MCU tag. |
| 2e8a:0009, 2e8a:000f | USB vendor:product of the RP2354A: running firmware (CDC, like a Pico 2) and BOOTSEL mode. |
| ACK | MCU reply (type 0x80) to a reliable request. Results: 0 APPLIED, 1 STAGED, 2 INVALID, 3 BUSY, 4 STALE, 5 NOT_READY, 6 UNSUPPORTED. |
| actionlint | Linter for GitHub Actions workflows. |
| Ag59800 PoE module | Silvertel PoE++ powered-device module. The board uses the Ag59824-LPB (24 V output, IC5, hand-soldered on the bottom side), a fixed Type 4 class 8 PD. Reports the PSE type on TYP2/TYP3. |
| AHRS | Attitude and heading reference system. A Mahony filter on the MCU. |
| AM32 | Open-source ESC firmware running on the ESCs. The image bundles an AM32 binary **[upstream]**; the MCU updates the ESCs over the signal lines (passthrough). |
| app | The separate pilot application. Out of scope. |
| arc42 | The architecture documentation template used for this wiki. |
| ATTITUDE | MCU telemetry frame 0x90 at 60 Hz: current and desired quaternion, desired depth, health bits, host and output age, motor commands. |
| BAT_IN | Battery input net from J6 pin 2. The LTC4162 measures vbat here, so vbat sags under thruster load. |
| BCM2712 | The CM5's SoC, as in the Raspberry Pi 5. Has no H.264 encoder. |
| BDU | Block data update. WSEN-PADS setting that keeps an output word consistent while it is read. |
| BMI270 | Bosch IMU, on the MCU's SPI1 (GP10-13), polled. Not on I2C. |
| BMS | Battery management system inside the pack. The only overcurrent protection on the ESC branch. |
| BOOTSEL | RP2354A boot ROM mode that accepts new firmware over USB (2e8a:000f). Entered when QSPI_SS is low while the chip leaves reset. On this board: hardware BOOTSEL (GPIO24 RUN, GPIO25 QSPI_SS). |
| Bx | Bring-up step x of phase 6, from B0 (inspection without power) to B16 (EMI). |
| BUSY | ACK result 3. For ESC_POWER: hold not over, settings not applied, stopping, upload, recovery or protocol transition. The host retries. |
| cachix | Binary cache for Nix. The builds use the nix-community and nixos-raspberrypi caches. |
| CAPS | Capability exchange. The host sends the legacy C5 request GET_CONTROL_CAPABILITIES; the MCU answers with frame 0x81: schema, sizes, feature bits (0x1f today; 0x20 = ESC power **[planned: Phase 2]**) and build identity. |
| capability catalog | The dynamic list of readings and actions the rov_firmware service offers the app. New mainboard values (`rov.*` readings, `rov.escPower.set`) use it, so the app contract stays unchanged. |
| CC/CV | Constant-current then constant-voltage charging. |
| CDC | USB communications device class (serial). The CM5 to MCU link; Linux driver `cdc_acm`. |
| CM5 | Raspberry Pi Compute Module 5: BCM2712 SoC, RP1 I/O chip, eMMC, EEPROM bootloader. |
| CM5 IO Board | Raspberry Pi's carrier board. Reference design for parts of the mainboard; test platform for the phase 3 spike. |
| `config.json` | ROV config on the device, `/home/pi/firmware/src/rov_firmware/config.json`. Persistent; the dev loop never overwrites it. |
| config.txt | Raspberry Pi firmware configuration, generated by nixos-raspberrypi. |
| CONTROL | Host frame 0x10: 8 direction values, source dt, flags (stabilization, depth hold, input valid). |
| CRC32C | Checksum of every extended protocol frame. |
| DShot | Digital ESC protocol, generated by PIO on the MCU. Speeds 150/300/600, 1200 only on RP2350. Bidirectional DShot: the ESC sends telemetry back on the same line. |
| eMMC | Flash storage on the CM5. Written through rpiboot over J8. |
| EMA | Exponential moving average. Battery % uses a 10 s EMA of vbat **[planned: Phase 4]**. |
| `en_jeita` | LTC4162 register 0x29 bit 0, default 1. Must be 0 so the charge current and voltage settings stick. Reading 1 after clearing it means the chip lost its registers. |
| ESC | Electronic speed controller. Two 4-in-1 boards: ESC A on J3 (M1-M4), ESC B on J4 (M5-M8). |
| ESC power switch (GP14 / ESC_PWR_EN) | Q3 driven by the photovoltaic MOSFET driver IC16 from GP14. Connects the battery to J14 (both ESCs). Static, no current limit. |
| ESC_POWER | MCU request 0x26, payload u32 0/1 **[planned: Phase 2]**. Never answered with NOT_READY. |
| FRD | Forward-right-down body frame of the IMU data. Level means acceleration of about (0, 0, -9.81) m/s². |
| `force_telemetry_on` | LTC4162 `config_bits` (0x14) bit 2. Keeps the measurement system running on battery only. The one charger write allowed before B9. |
| go2rtc | Streaming server on the CM5. Streams `cam` (camera 1) **[upstream]** and `cam2` (camera 2) **[planned: Phase 3]**; API :1984, WebRTC :8555. |
| health bits | ATTITUDE `health_flags`: bit 0 IMU healthy, bit 1 pressure healthy, bit 2 output permitted by all gates, bit 3 raw override **[upstream]**. Bits 4-6: ESC power state 0 absent, 1 off (hold), 2 off (ready), 3 starting or arming, 4 on, 5 stopping **[planned: Phase 2]**. The host reads only bits 0 and 3 today. |
| HELLO | Host frame 0x01 that opens a session. The MCU neutralizes outputs and needs a settings commit before control. |
| host-loss timer | The MCU switches ESC power off 30 s after the last valid host packet; paused during an ESC update or recovery **[planned: Phase 2]**. |
| HQ camera | Raspberry Pi High Quality camera (Sony imx477). Needs a 22-to-15 pin cable on this board. |
| I2C1 | CM5 I2C bus on GPIO2/GPIO3, at most 400 kHz: LTC4162, SHT45, WSEN-PADS, MS5837. |
| impermanence | NixOS module that mounts `/` as tmpfs and bind-mounts listed paths from the persistent partition. |
| JEITA | Temperature-dependent charge profile from the JEITA guideline. The board has no pack NTC; a fixed 10 kΩ/10 kΩ divider makes the LTC4162 read 25 °C. |
| LAD | The LTC4162-L variant on the board (LTC4162IUFD-LAD, chem code 0): lithium-ion, charge voltage set over I2C, no MPPT. |
| lgpio | Python GPIO library. On the CM5 it uses the gpiochip labelled `pinctrl-rp1`. |
| libav | FFmpeg libraries. `rpicam-vid` uses them for software H.264 on the CM5 **[planned: Phase 3]**. |
| LLDP | Link Layer Discovery Protocol. Some PSEs deliver at most 15.4 W until a PD confirms its class over LLDP. Not used here. |
| LTC4162 charger | Analog Devices LTC4162-L buck charger (IC8) at I2C 0x68. Strapped for 5 cells. Sense resistors RSNSB 10 mΩ (battery, R20) and RSNSI 8 mΩ (input, R1). |
| magnet switch | External switch board on J12. Its MAG_ON signal enables load switch IC15, a hard cut of the switched 5 V rail. Not readable by the CM5. |
| maintenance | Request ENTER_MAINTENANCE 0x25. The MCU goes neutral and closes the session, for example before an ESC firmware upload. |
| manafish-firmware | systemd unit of the rov_firmware service. |
| mock WebSocket server | `uv run tools`, "Run Mock Websocket Server Locally": app work without hardware **[upstream]**. |
| MS5837 | Depth (pressure and temperature) sensor module on J1, I2C 0x76, read at 15 Hz **[upstream]**. |
| nixos-raspberrypi | Flake with NixOS modules for Raspberry Pi boards; the CM5 image uses `raspberry-pi-5.base` **[planned: Phase 3]**. |
| NOT_READY | ACK result 5. The host drops the whole session when it gets one. |
| nRPIBOOT | CM5 pin that forces boot from USB. Jumper J7 pins 9-10. |
| PD | Powered device: the PoE receiving side, here the Ag59800 PoE module. |
| Phase N | Work package N of the mainboard port plan, 0 to 6 (see [Home](Home)). |
| picotool | Raspberry Pi tool that loads firmware into an RP2 chip in BOOTSEL. Used as `picotool load -v -x` (verify, execute). `-f` forces a USB reboot into BOOTSEL; not used on the mainboard. |
| Pico control protocol v1 | The CM5 to MCU protocol: [PICO_CONTROL_PROTOCOL.md](https://github.com/Tropaion/Manafish_Mainboard/blob/main/firmware/docs/PICO_CONTROL_PROTOCOL.md). |
| Pico SDK | Raspberry Pi C SDK, version 2.3.1, fetched by CMake at build time. |
| `pinctrl-rp1` | Label of the RP1 gpiochip on the CM5. |
| PoE types | PSE types of IEEE 802.3af/at/bt, by classification events: Type 1 up to 15.4 W, Type 2 30 W, Type 3 60 W, Type 4 90 W, all at the PSE. |
| PSE | Power sourcing equipment: PoE switch or injector at the surface. |
| `PSU_MAX_CURRENT` | CM5 EEPROM setting, 5000 here, because the CM5 cannot detect its supply over USB-C. |
| QSPI_SS | Chip select of the RP2354A's in-package flash, driven by CM5 GPIO25. Low during reset selects BOOTSEL. |
| recovery5 | usbboot directory used to update the CM5 bootloader EEPROM. |
| RP1 | The CM5's I/O controller; provides the GPIO lines. |
| RP2354A (MCU) | RP2350 in QFN-60 with 2 MB in-package flash, stepping A4. Runs `firmware/`. |
| rpiboot | Raspberry Pi usbboot tool: boots the CM5 over USB, e.g. `mass-storage-gadget64` to expose the eMMC. |
| rpicam-vid | Raspberry Pi camera capture and encode tool, run by go2rtc. |
| `rov.*` readings | Capability readings of the service, e.g. `rov.batteryVoltage`, `rov.poeType`, `rov.hullTemperature` **[planned: Phase 4]**. |
| rov_firmware service (manafish-firmware) | The Python service on the CM5 (import package `rov_firmware`, distribution `manafish`). Code in `software/src/rov_firmware`. |
| RUN | RP2354A reset input, active low, driven by CM5 GPIO24. |
| session | Extended protocol session opened by HELLO; ENTER_MAINTENANCE and the safety latch close it. |
| SHT45 | Sensirion humidity and temperature sensor (IC12) at I2C 0x44, on a slotted board tongue. |
| smbus2 | Python I2C/SMBus library used for the charger and hull sensors **[planned: Phase 4]**. |
| spike | One-day test of the CM5 NixOS image on the CM5 IO Board, phase 3. Decides NixOS or the fallback. |
| subtree | `git subtree add/pull --prefix=<dir> --squash`: upstream history squashed into one commit, base SHA recorded. |
| SWD | Serial Wire Debug of the RP2354A: CM5 GPIO8 (SWDIO), GPIO11 (SWCLK) and connector J2. |
| `system_status` | LTC4162 register 0x39: bit 1 `vin_gt_4p2v` (PoE present), bit 2 `vin_gt_vbat`, bit 8 `en_chg`. |
| `telemetry_valid` | LTC4162 register 0x4A bit 0. Telemetry counts as valid only after it is set and one conversion has passed. |
| `thrust_permitted` | MCU runtime hook that gates motor output on the ESC power state **[planned: Phase 2]**. |
| tmpfs | RAM file system. The CM5 root file system. |
| ty | Python type checker used in the software gate. |
| TYP2, TYP3 | Ag59800 type-detect outputs, read through optocouplers on CM5 GPIO6 and GPIO12, active low. |
| UF2 | Firmware file format for RP2 chips. Release asset `mainboard-vX.Y.Z-mb.N.uf2`. |
| Unity | C unit-test framework of the MCU host tests. |
| upstream | [manafishrov/mcu-firmware](https://github.com/manafishrov/mcu-firmware) (in `firmware/`) and [manafishrov/firmware](https://github.com/manafishrov/firmware) (in `software/`). |
| uv | Python package and environment manager used in `software/`. |
| VSYS | Charger output rail; feeds the 5 V buck IC9. |
| WSEN-PADS | Würth absolute pressure sensor (IC10) at I2C 0x5C, WHO_AM_I 0xB3. Measures hull pressure. |
| XOSC | Crystal oscillator of the RP2354A. Its start-up delay multiplier is raised to 64 for Y1 **[planned: Phase 2]**. |

|---|---|
| IC3 | MagJack (Ethernet with PoE center taps) |

| IC8 | LTC4162 charger |
| IC9 | 5 V buck (TPSM53604), always-on rail +5V_AON |
| IC10 | WSEN-PADS |
| IC12 | SHT45 |
| IC15 | Load switch (TPS22965), switched by MAG_ON |
| IC16 | Photovoltaic MOSFET driver of the ESC power switch |
| Q3 | ESC power MOSFET |
| R1, R20 | LTC4162 input and battery sense resistors |
| R31 | 180 Ω from GP14 to the IC16 LED |
| Y1 | 12 MHz crystal of the RP2354A |
| J1 | MS5837 connector |
| J2 | SWD connector |
| J3, J4 | ESC A, ESC B signal connectors |
| J5, J11 | Camera 1 (MIPI0), camera 2 (MIPI1) |
| J6 | Battery, XT60 |
| J7 | CM5 jumper header (nRPIBOOT, EEPROM write protect, ...) |
| J8 | USB-C service port, data only |
| J9 | CM5 GPIO breakout |
| J12 | Magnet switch connector |
| J13 | RP2354A GPIO breakout (GP22-29) |
| J14 | ESC power output, XT60 |
